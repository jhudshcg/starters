## Fidelity and remaining limits

- PDF extraction was checked for page coverage, hashes, native-character retention and linked assets. Native code uses layout-preserving text where detected. PDF table images retain merged-cell geometry; Markdown columns are positional.
- Visual sampling covered representative assessment images and tables; this is not word-for-word or pixel-level certification. Image text is not automatically transcribed. Inspect a linked figure before relying on its contents.
- A known open-bottom table on live scheme p17 was repaired structurally. Overlapping extracted Grade A contents text was separated after visual comparison. Source mistakes remain unchanged.
- Workbooks: all exported literals, formulas and cached results matched source cells at conversion. The HTML view approximates layout; theme/tint colours, exact number formatting, printing and interactive spreadsheet behaviour are not reproduced. No browser visual certification has been performed. Original XML preserves features that openpyxl does not fully understand.
- Conversions live in the sibling `agents` tree, outside this site repository; site commits alone do not back them up. Scripts and manifests are in this repository.

## Reuse and regeneration

- PDF/DOCX manifest: [conversion-manifest.json](../../references/esp/conversion-manifest.json). Workbook manifest: [workbook-manifest.json](../../references/esp/workbook-manifest.json). Each source-adjacent Markdown file has a provenance sidecar.
- Do not reconvert unchanged resources. Read published outputs directly. `python3 scripts/check-esp-conversions.py` can restore the published PDF/DOCX cache to temporary staging and check it; note it rewrites the local manifest publication flag for its current operation.
- Only for missing/changed PDF/DOCX resources: `python3 scripts/convert-esp-resources.py --match <filename-fragment>`, then check and publish with `scripts/check-esp-conversions.py --publish`.
- Workbook converter: `python3 scripts/convert-esp-workbooks.py`; `--publish` copies staged exports beside sources. Its cache is temporary-staging-based, so do not rerun merely because staging disappeared: use the published exports/manifest.
- Publishing outside the workspace requires sandbox approval; ordinary read-only reuse does not. Use non-login shells for escalated Python commands to avoid an unrelated pyenv startup lock.
- Tooling: installed pdfplumber 0.11.9, pypdfium2 5.5.0, Pandoc 3.11; openpyxl version recorded by workbook guides. See [requirements](../../scripts/requirements-esp.txt).

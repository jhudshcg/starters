See the register for fidelity limits and checks; do not repeat unchanged conversions.

The teacher-confirmed Core specification baseline is 1.1. Distinguish assessment requirements, examiner judgements, student examples and original practice designs. Student exemplars are not flawless reference implementations; starter marks are not ESP grades.

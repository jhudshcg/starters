# Starter specifications

Start content work with the two shared guides below, then the relevant type specification. These own the specialist requirements linked from [AGENTS.md](../AGENTS.md); requirements moved from the root retain their original status, even in documents containing drafts. Explicit recorded teacher decisions supersede older defaults. **Proposal** rules remain drafts; the shared authoring/refinement guides are adopted.

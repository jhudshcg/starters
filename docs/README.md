Status: draft for review. These documents elaborate [AGENTS.md](../AGENTS.md); they do not override it. Rules labelled **Proposal** resolve gaps for review before the affected implementation begins. Unlabelled requirements restate or operationalise the brief.

Use the same terms throughout: **type**, **focus**, **question**, **part**, **variation**, **set**, **attempt**. Do not rotate synonyms for variety. Vary scenarios, values and reasoning demands when educationally useful.

The examples are original draft content, not approved exam-board questions. They define behaviour and need content review before publication. No full curriculum coverage is claimed by this draft.

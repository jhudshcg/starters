# OS Task outlines, objectives and activity/question ideas

The Occupational Specialism is a 1.5 month 'exam' where students research, design, develop, test and evaluate their own website/app to meet a set of client requirements. This process is divided into 3 tasks.

The starters webapp should offer questions and activities to support students in preparing for the OS and practising some of the skills they will need.

OS Practice will be a separate page within the exam practice section of the app.

## Task 1

Research, business case, functional and non-functional requirements, KPI, acceptance criteria, features, user stories, site map, UI design, schema design, algorithm design (flow charts), code snippet collection

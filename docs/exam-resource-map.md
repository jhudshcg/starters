## Use without loading the whole collection

1. Select Core Paper 1 (**19610**), Core Paper 2 (**19611**), ESP (**19612**) or OS, then the exact specimen/series and task.
2. Start with existing local notes/extracts; [ESP source guide](esp/source-guide.md) and [task notes](esp/tasks-and-assessment.md) may avoid repeat extraction. Confirm referenced paths still exist after reorganisation.
3. Read only the required question/task and marking section. Add examiner commentary for misconceptions, or grade exemplification for response quality. Keep contexts/series matched; names alone do not establish that exemplars belong to a particular SAM.
4. Cache any new reusable extraction with source path, version and page/question identifiers. Keep full PDFs, unrelated tasks and historical specifications out of working context unless needed.

This map routes work; it does not certify resource contents, currency or assessment equivalence.
